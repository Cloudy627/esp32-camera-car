## 02 修改串口心跳周期

- 日期：2026-07-20
- 实验目标：理解修改、编译、烧录和运行验证的完整流程。
- 代码修改：将 `delay(1000)` 改为 `delay(2000)`。
- 预期结果：相邻心跳的 `uptime` 相差约 2000 ms。
- 实际结果：符合预期。
- 遇到的问题：烧录时提示串口 `/dev/cu.usbserial-10` 被占用。
- 原因：串口监视器仍在占用 CH340C 串口。
- 解决方法：关闭串口监视器后重新烧录，烧录完成后再打开监视器。
- 实验结论：编译只生成固件，烧录才会更新 ESP32；烧录与串口监视不能同时占用同一个串口。
