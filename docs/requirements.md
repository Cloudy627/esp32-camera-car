# 第一阶段需求与验收标准

## 阶段目标

完成一个能够通过手机查看实时画面、控制四轮运动并在控制异常时自动停车的 ESP32-CAM 小车原型，同时保留可追溯的设计、测试和 Git 证据。

## 范围

- 验证 ESP32-CAM 最小系统、工具链、烧录和串口输出。
- 验证 OV3660、PSRAM、Wi-Fi 热点、网页和 MJPEG 视频。
- 完成两块 TC1508A、四台 TT 电机和独立供电系统的装配。
- 通过网页控制双侧同向和两种差速组合动作。
- 提供松手停止、断线停车、通信超时停车和单次动作时间上限。
- 记录实际结果、失败过程、安全约束和已知限制。

## 非目标

- AI 视觉识别或自动驾驶。
- 编码器反馈、PID 调速或精确轨迹控制。
- 正式 PCB、线束、外壳和量产设计。
- 堵转电流、极限负载、续航或长期可靠性认证。

## 结论边界

- `500 ms` 通信超时和 `5000 ms` 动作上限是源码中的设计参数；本阶段没有使用专用仪器测量实际停车延迟。
- 10 分钟和 11 次是本次验收的覆盖范围，不能外推为长期可靠性或寿命结论。
- “无异常”是用户在本次测试条件下的现场观察，不表示所有电气与机械风险已经消除。
- 原始串口日志、照片或视频只有在实际保存并加入仓库后才能作为附加证据；本文不补造缺失材料。
