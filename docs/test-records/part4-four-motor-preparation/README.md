# 第 4 部分：四电机测试准备与异常排查

- 开始日期：2026-08-15
- 最近更新：2026-08-17
- 原工作分支：`test/day4-four-motor-drive`
- 当前状态：测试固件已完成编译；硬件装配尚未完成，四电机动作未实机验证
- 测试范围：每侧使用一块 TC1508A，同侧前后电机分别连接 `MOTOR-A` 和 `MOTOR-B`

## 目标与 GPIO 分配

本部分为四电机空载基础运动测试做准备。测试固件将每次动作限制为 `1.5 s`，动作之间停止 `2 s`。

| 功能 | ESP32-CAM | TC1508A |
| --- | --- | --- |
| 左侧方向输入 1 | GPIO13 | 左侧驱动 `IN1/IN3` |
| 左侧方向输入 2 | GPIO14 | 左侧驱动 `IN2/IN4` |
| 右侧方向输入 1 | GPIO12 | 右侧驱动 `IN1/IN3` |
| 右侧方向输入 2 | GPIO15 | 右侧驱动 `IN2/IN4` |
| 启动倒计时提示 | GPIO4 | 板载白色闪光灯 |

GPIO12 和 GPIO15 是 ESP32 启动配置脚。电机电源必须在 ESP32-CAM 完成启动后才接通；驱动板带电期间不得重启 ESP32-CAM。

## 固件状态

测试固件上电后等待 25 秒，再用白色闪光灯倒计时 5 秒，随后执行：

1. 左侧方向 A、停止、左侧方向 B、停止。
2. 右侧方向 A、停止、右侧方向 B、停止。
3. 两侧方向 A、停止、两侧方向 B、停止。
4. 两种相反方向组合，分别用于检查差速转向。
5. 最终保持停止。

在机械安装方向和电机极性完成实测前，只使用“方向 A/B”，不提前写成前进或后退。

## 异常上电记录

当 TC1508A 和 AA 电池电源已经接通后，再给 ESP32-CAM 接入充电宝，电机曾短暂转动一下后停止。发现异常后立即断开两套电源，没有继续重复测试。

原因判断为上电顺序不符合约定：ESP32-CAM 启动期间 GPIO 尚未稳定为停止状态，GPIO12/GPIO15 还可能影响启动。该现象没有被用来判定驱动板或电机损坏。

后续固定顺序为：

1. 保持电机电源断开。
2. 先给 ESP32-CAM 上电并等待启动完成。
3. 最后接通 AA 电池电机电源。
