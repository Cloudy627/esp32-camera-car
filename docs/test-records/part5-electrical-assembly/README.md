## 本部分范围

母弯排针尚未到货，因此本部分不固定 ESP32-CAM，也不进行通电测试。目标是完成两块安全 TC1508A、四台 TT 电机、电机电源并联和面包板低电流控制信号的断电装配。

## 已完成装配

### 电机与驱动板

- 左侧 TC1508A 在第 4 部分已经连接两台电机。
- 右侧两台电机分别焊接到第二块 TC1508A 的 `MOTOR-A` 和 `MOTOR-B`。
- 电机远离底板的端子使用红线，靠近底板的端子使用黑线；该线色规则只记录物理接法，不代表车轮方向已经验证。
- 两块 TC1508A 的 `+` 使用与电池盒引线粗细相近的红线并联。
- 两块 TC1508A 的 `-` 使用与电池盒引线粗细相近的黑线并联。
- 当前未安装船型开关；电机供电仍由电池盒插入或取出电池来断开。

### 面包板信号分配

面包板只承载 GPIO 控制信号和逻辑共地，不承载电机电流。`1～10` 行预留给母弯排针和 ESP32-CAM，现有分配如下：

| 面包板位置 | 当前连接 | 后续 ESP32-CAM 连接 |
| --- | --- | --- |
| 第 15 行左半区 | 左侧驱动 `IN1/IN3` | GPIO13 |
| 第 17 行左半区 | 左侧驱动 `IN2/IN4` | GPIO14 |
| 第 19 行左半区 | 右侧驱动 `IN1/IN3` | GPIO12 |
| 第 21 行左半区 | 右侧驱动 `IN2/IN4` | GPIO15 |
| 第 25 行左半区 | 驱动板公共负极引出的细黑线 | ESP32-CAM `GND` |

公共地细黑线只提供逻辑参考。电机主回流仍经过电池盒和驱动板之间的粗黑线，不经过面包板或普通杜邦线。

检查期间先取出一节 AA 电池，之后将电池盒内剩余电池全部取出，并保持 USB 和充电宝断开。

| --- | --- | --- |
| 驱动电源 `+` 对 `-` | 万用表 `200 Ω` 档显示 `OL` | 未发现明显硬短路 |

| 两块驱动板 `-` 之间 | 用户报告导通正常 | 黑色负极并联线连续 |
| 右侧 `MOTOR-A` 输出回路 | 用户报告阻值检查正常 | 未发现明显断路或短路 |
| 右侧 `MOTOR-B` 输出回路 | 用户报告阻值检查正常 | 未发现明显断路或短路 |
| 面包板第 15/17 行之间 | 用户报告隔离检查正常 | 左侧两路方向信号未发现短接 |
| 面包板第 19/21 行之间 | 用户报告隔离检查正常 | 右侧两路方向信号未发现短接 |

“检查正常”仅表示用户在现场按约定量程检查后报告符合成功判据；未记录的具体数值不补写为估计值。
